# Texture nodes in Blender 4.5.14 LTS

Generated by `tools/gen_reference.py` from what Blender 4.5.14 LTS reports about itself (`skills/blender/inventory/`, read by `skills/blender/scripts/inventory.py`). **default** is the value Blender registers; **new** is what a node, modifier or constraint made from Python actually starts with (≠ where they differ); **factory** is what a fresh file holds. Look one item up from the command line with `skills/blender/scripts/kb.py`.

40 node types can be added to a `TextureNodeTree`. Sockets marked *hidden* are off until a node setting turns them on (a Math node's third input, a Mix node's typed sockets). Add a node with `tree.nodes.new("<idname>")`; reach a socket by name (`node.inputs["Base Color"]`) or, when names repeat, by identifier.
